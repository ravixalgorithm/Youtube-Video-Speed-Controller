# YouTube Video Speed Controller

A lightweight and user-friendly Chrome extension that lets you control YouTube playback speed with ease — up to **5x**!

## 🚀 Features

- Control YouTube video playback speed from 0.1x to 5x.
- Intuitive UI overlay on the video player.
- Keyboard shortcuts for faster speed adjustment.
- Remembers your preferred speed for future videos.
- Clean and minimal interface.
- Works seamlessly with the YouTube player.

## 📦 Installation

1. Download or clone this repository:
    ```bash
    git clone https://github.com/your-username/youtube-video-speed-controller.git
    ```
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer Mode** (top-right corner).
4. Click **"Load unpacked"** and select the extracted folder.

## 🛠 Usage

- Use the extension's on-screen controls to change speed.
- Alternatively, use keyboard shortcuts:
  - `[` – Decrease speed
  - `]` – Increase speed
  - `\` – Reset to 1x

## 🔧 Customization

You can customize the default speed or UI behavior by editing the relevant values in the extension's JavaScript files. Look inside `content.js` or similar files (see comments in the code).
